# Smart Student Club Management Dashboard

A modern Flutter app for managing college student clubs — events, members, announcements, attendance and analytics.

## Features

- **Dashboard** – Live stats, upcoming events, recent announcements
- **Clubs** – Browse & manage clubs with categories and member counts
- **Events** – Create / view events with date, venue, RSVP status
- **Members** – Member directory with roles (Admin, Lead, Member)
- **Announcements** – Club-wide notices and updates
- **Attendance** – Simple attendance tracking for events
- **Modern UI** – Material 3 + Google Fonts (Poppins)

## How to Run

```bash
cd smart_club_dashboard
flutter pub get
flutter run
```

## Requirements

- Flutter SDK 3.0+
- Android / iOS emulator or device
